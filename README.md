# Lua Cookbook: Mastering Lua from First Principles

This repository contains a comprehensive Lua cookbook designed to help you master the Lua programming language from first principles. The cookbook provides executable code examples for all major Lua concepts, organized in a progressive manner from basic to advanced topics.

## Purpose

The purpose of this cookbook is to:

1. Provide a hands-on learning resource for Lua
2. Demonstrate Lua concepts with executable examples
3. Serve as a reference for Lua programming techniques
4. Guide learners through a logical progression of Lua concepts

## Structure

The cookbook is organized into the following sections:

1. **Basics**: Variables, data types, operators, and strings
2. **Control Structures**: Conditionals and loops
3. **Functions**: Definitions, arguments, closures
4. **Tables**: Creation, access, iteration
5. **Metatables and Metamethods**: Custom behavior for tables
6. **Object-Oriented Programming**: Classes, inheritance
7. **Modules and Packages**: Code organization
8. **Error Handling**: pcall, xpcall, error
9. **Standard Libraries**: string, table, math, os
10. **Advanced Concepts**: Coroutines, weak tables
11. **Best Practices**: Performance tips, code organization

## How to Use

1. Clone this repository
2. Open `lua_cookbook.lua` in your favorite text editor
3. Uncomment the section you want to study
4. Run the file with the Lua interpreter:
   ```
   lua lua_cookbook.lua
   ```
5. Observe the output and experiment with the code

## Prerequisites

- Lua 5.1 or later installed on your system
- Basic understanding of programming concepts
